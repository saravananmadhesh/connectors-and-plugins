# Changelog

Notable changes. Versioning follows Git tags on the repository, not package versions. Format: [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [Unreleased]

### Removed

- **Partner API:** `ptk_` keys, partner apps, host-created orgs and `X-Act-As-User`; hosts use projects and the client package (migration `0001_remove_partner_apps`).
- **Teams:** team scope, team keys and team routes; "For team" is the organization (migration `0002_remove_teams`).

### Added

- **Foundation:** pnpm monorepo with five apps (`web`, `admin`, `api`, `gateway`, `worker`) and shared packages; strict TypeScript project references; Oxlint, Oxfmt, Vitest; one-command Docker-free gate (`pnpm test`) with an HTML report; `pnpm dev` with embedded Postgres, Mailpit, object store and a log dashboard; Azure DevOps CI; one root `Dockerfile` with a target per app.
- **Platform core:** Drizzle schema and generated migrations with a migration lint, row-level security and per-service database roles; Zod route registry and error registry under `/v1`; shared Fastify bootstrap with a fixed middleware order, idempotency and graceful shutdown; ports and adapters (cache, queue, lock, blob, email, limiter, KMS, secrets).
- **Identity and tenancy:** Argon2id accounts, email verification and reset, sessions, organizations, invites, roles, one `authorize()` for every route, audit log, account and org lifecycle.
- **Plugins and installs:** marketplace catalog, plugin versions, install at org or user scope with role enforcement, encrypted variables, `pinned` and `follow_latest` updates, required installs, replaced-install display.
- **MCP servers:** per-installation MCP configuration (none, API key, OAuth with dynamic registration or client id), per-member OAuth with PKCE, SSRF-guarded probing and tool discovery, HPKE sealing with KMS-wrapped org keys.
- **Gateway and delivery:** Bearer API keys (organization For You and Platform keys, project keys and session keys), stateless MCP gateway (`/mcp`, `/{server}/mcp`), sync manifest and brokered archive download through the gateway host, delivery outbox.
- **Admin app:** allow-listed sign-in, plugin sources, discover preview, queued ingestion, approve, publish, yank, deprecate, suspend, delete with impact dialog, categories, audit viewer, light and dark theme.
- **Web UI:** scope-wise install, required installs, MCP servers, API keys and "connect your agent" snippets.
- **Web UI navigation:** one switcher for the organization (menu of recent entries, search with Ctrl/Cmd+K), a Manage group that follows the chosen scope with the same page names in both, breadcrumbs, page-specific window titles, a skip link and tooltips; focus rings and input borders meet WCAG contrast, guarded by a test.
- **Examples:** deepagents clients in Python and Node.js (`examples/deepagents`).
- **Tests:** unit, client, security, conformance, protocol, integration and browser suites; opt-in staging and load suites; mutation testing.

### Changed

- The connector service and separate connections were removed; MCP configuration lives on the installed `mcp_server`.
- Dependency versions are managed through the pnpm catalog.
- The OpenAPI documents are generated by `pnpm build` (contracts package) into the git-ignored `docs/openapi/`; the committed copies and the drift test are gone.
- Documentation was reduced to a minimal set under `docs/` (product, architecture, guides); the planning and tracker documents were removed (kept in the `docs-archive-pre-cleanup` tag).
