  • Request rate, latency, in-flight work and errors are application metrics.

Reading historical metrics
  • Counters are converted to rates or totals over the selected interval; gauges are summarized as time-weighted averages/maxima.
  • Latency percentiles are derived from histogram buckets, not averaged across samples.
  • Yearly history is available only if the metrics backend retains it; otherwise show an explicit unavailable state, never fabricate values.
  • Use these summaries for capacity and trend analysis. Use Live status and alerting for current conditions.
