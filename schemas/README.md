# Schemas

| File | What it validates | Origin |
| --- | --- | --- |
| `cursor-plugin.schema.json` | `plugins/*/.cursor-plugin/plugin.json` | Copied from [cursor/plugins](https://github.com/cursor/plugins) at commit `9580c23` (MIT) |
