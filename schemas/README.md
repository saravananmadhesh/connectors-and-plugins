# Schemas

| File | What it validates | Origin |
| --- | --- | --- |
| `cursor-plugin.schema.json` | `third_party/*/.cursor-plugin/plugin.json` | Copied from [cursor/plugins](https://github.com/cursor/plugins) at commit `9580c23` (MIT) |
| `cursor-marketplace.schema.json` | `.cursor-plugin/marketplace.json` | Same as above |
| `boldcreate.schema.json` | `third_party/*/boldcreate.json` (source) | Ours: transport, auth, phase and other BoldCreate-only metadata |
| `boldcreate-plugin.schema.json` | `third_party/*/.boldcreate-plugin/plugin.json` (generated) | Ours: the full manifest BoldCreate Connect ingests |
| `boldcreate-marketplace.schema.json` | `.boldcreate-plugin/marketplace.json` (generated) | Ours: the BoldCreate marketplace index |

Claude Code manifests (`.claude-plugin/plugin.json`) are generated by `scripts/build.mjs`. Run `claude plugin validate third_party/<name>` for Anthropic's own check.
